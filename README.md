# Quản lý học sinh tăng cường

Ứng dụng web nội bộ dành cho quản lý học sinh học tăng cường.

## Trạng thái hiện tại

Dự án mới hoàn thành bước đặc tả kỹ thuật.
Chưa kết nối Firebase.
Chưa xây dựng chức năng nghiệp vụ.

## Chạy dự án

1. Cài Node.js.
2. Chạy npm install.
3. Chạy npm run dev.

## Kiểm tra

- npm run typecheck
- npm run build
